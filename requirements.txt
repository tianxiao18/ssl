# Minimal, tested dependency set for the detection pipeline (scripts/, vox_tracer/).
#
# Install this FIRST, then install the two heavyweight, --no-deps-only packages:
#     pip install -r requirements.txt
#     pip install -e sam3/ --no-deps
#     pip install inference==1.2.12 --no-deps
#
# Both need --no-deps for the same reason: each pulls in a dependency list far
# outside what we actually use, and each conflicts with the rest of this file
# if pip is left to resolve it normally.
#   - sam3/pyproject.toml pins numpy>=1.26,<2 and ftfy==6.1.1 exactly, both of
#     which conflict with what's pinned below (numpy 2.x is what
#     scipy/scikit-image/pandas here are built against; ftfy 6.3.x is what's
#     actually been running). sam3's *other* runtime deps (timm, ftfy, iopath,
#     regex, typing_extensions, huggingface_hub) are still needed, so they're
#     pinned below instead, at versions confirmed compatible with numpy 2.x
#     rather than sam3's own (looser, older) declared minimums.
#   - inference (Roboflow's package, used only for scripts/run.py das_yolo's
#     `from inference import get_model`) pulls in an entire unrelated server
#     stack (aiohttp, boto3, docker, fastapi, redis, twilio, anthropic,
#     slack-sdk, ...) and pins click<8.2.0, which directly conflicts with
#     huggingface_hub's click>=8.4.0 pinned below -- `pip install -r
#     requirements.txt` fails outright if inference is left in this file.
#     get_model() only needs numpy/opencv/torch, all already pinned below.
